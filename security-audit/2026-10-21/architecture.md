# Architecture (scoped delta audit)

tsk is a single-user local terminal task board (Rust TUI and headless CLI) and the Herdr plugin `herdr-tsk`. The human at the keyboard and agents invoked as that same OS user share one JSON store. There is no tenant authenticator. The OS account is the isolation boundary for the board. This pass does not re-open that model. Comparable baseline: a local-first CLI kanban plus a static marketing page. Author-written page copy is ordinary site content. Same-origin script that only paints its own literals does not cross a visitor trust boundary.
