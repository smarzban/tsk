**tsk is a terminal task board for you and your agents: one shared queue, a TUI for you, a CLI for them.**

Use it beside your agent in Herdr, or run `tsk` in any terminal. Both show the same tasks.

## Start here

1. [Install tsk and connect Herdr](/docs/install/).
2. Open the board. Four starter tasks (`N1`…) on the desk show you around: open one with `Enter`, and clear it with `ctrl+d`, `ctrl+f`, or `ctrl+x`.
3. Press `+`, type a title, and press `Enter`. The task lands in the `open` inbox.
4. Pick it with `ctrl+n` when you are ready, then open it for notes and steps.
5. Give your agent its task number.

Agents read tasks with `tsk list` and update them with `tsk status`. [Install the agent skill](/docs/install/#agent-skill) so your agent knows the workflow. To have tsk launch an agent on a task in its own worktree, see [Dispatch](/docs/dispatch/).

After an upgrade, a `What's new in tsk` task lands on the desk. Clear it like a starter task.

## Find your work

**No project setup needed.** Open tsk in a project directory and add a task: the project appears on your board. To add a task to another project, put `!p /path/to/project` in the title in quick-add, or pass `-p /path/to/project` to `tsk add`.

| View | Use it for |
| --- | --- |
| **desk** | Work that needs you or is in motion across projects, plus tasks with no project |
| **project** | One project's tasks |
| **projects** | Browse projects, or follow a thread across them |

| Section | Contains |
| --- | --- |
| **NEEDS YOU** | Tasks blocked on you, and work waiting for your review |
| **IN MOTION** | Started tasks, and tasks waiting on someone else |
| **ON DECK** | Picked `ready` tasks, then the `open` inbox |

You or your agent set a task's status. Checking off every step, or an agent session ending, does not mark a task done.
